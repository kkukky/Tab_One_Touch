# Tab_One_Touch

갤럭시탭(1920×1200 가로) 개인 전용 출퇴근 원터치 앱입니다.

- 현재 시간(초 포함), 오늘의 메시지, 하단 버튼 4개(출근, 퇴근, 소스, 기타)
- 테마 버튼 3개, 설정 버튼
- 설정에서 폴더를 고르면 그 안에 `Tab_One_Touch` 폴더를 만들고, `오늘의메시지.txt`로 오늘의 메시지를 읽고 저장합니다.

## APK 받기

https://github.com/kkukky/Tab_One_Touch/releases/latest

`main`에 푸시하면 GitHub Actions가 APK를 새로 빌드해 `latest` 릴리스에 올립니다. 디버그 서명 APK라서 설치할 때 "출처를 알 수 없는 앱" 허용이 필요할 수 있습니다.
